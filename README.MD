## 🧩 Exercício 1

### 📖 Enunciado
Implemente um programa em C que utilize **lista simplesmente encadeada** para armazenar números inteiros.  
O programa deve oferecer ao usuário um menu de opções:

1. Inserir número **no final** da lista.  
2. Criar uma função que **busque** um valor na lista.  
3. Escrever uma função que **remova o último elemento**.  
4. Modificar a inserção para **manter os elementos ordenados**.  

---

### ⚙️ O que o programa faz
- Permite **inserir valores no final** da lista ou de forma **ordenada**.  
- Possui uma função que **busca** um valor digitado pelo usuário.  
- Permite **remover o último elemento** da lista.  
- Exibe todos os valores armazenados.  
- Utiliza **alocação dinâmica** e **ponteiros** para gerenciar os nós.

## 🧠 Exercício 2

### 📖 Enunciado
Implemente um programa em C que utilize **lista simplesmente encadeada** para armazenar números inteiros.  
O programa deve oferecer ao usuário um menu de opções:

- Inserir número **no início** da lista.  
- **Exibir todos** os números da lista.  
- **Remover o primeiro** número da lista.  
- **Sair.**

---

### ⚙️ O que o programa faz
- Permite **inserir novos elementos no início** da lista.  
- Exibe todos os números armazenados na ordem em que estão encadeados.  
- Permite **remover o primeiro elemento** (início da lista).  
- Exemplo de manipulação básica de lista encadeada com **ponteiros e alocação dinâmica**.
